Helicopter Animation Project

This project features a 3D helicopter simulation with interactive animations. The helicopter's rotor blades rotate continuously, creating a realistic flight effect. Users can control various aspects of the simulation using keyboard and mouse inputs:

  • Camera Rotation: Pressing the left arrow (←) and right arrow (→) keys rotates the camera clockwise and anticlockwise, respectively.
  • Takeoff & Landing: Pressing the up arrow (↑) key makes the helicopter take off, while pressing the down arrow (↓) key initiates landing.
  • Lighting Effects: With each mouse click, the light source moves around the helicopter, enhancing the visual effects.
  • Sound Effects: Distinct sound effects accompany both the takeoff and landing actions for an immersive experience.

Note Software – Desktop Note-Taking Application

Note Software is a desktop application designed for efficient and convenient note-taking. Users can create and save notes directly to their local devices, ensuring easy access and data security. The software provides customization options, allowing users to modify the font color and background color of their notes for a personalized experience.

Additionally, users can open existing files, seamlessly insert the current date and time through the Edit menu, and utilize essential text editing functionalities, including cut, copy, paste, replace, and undo.
